# Project Status

> 更新时间：2026-08-12
>
> 当前阶段：P0 电脑端 Web Prototype——需求与技术设计基本完成，正在进入 UI 结构设计和第一条功能链开发

## 1. 当前结论

项目目前已经完成了“要做什么、第一版不做什么、采用什么技术栈、数据如何流动、前后端通过哪些 API 沟通”的初步设计。

React 前端项目已经初始化并成功运行，但现在显示的仍然是 Vite 默认页面，尚未实现学习应用的真实界面和功能。后端项目尚未初始化，学习库读取、Markdown 渲染、反馈保存和 AI 生成均尚未实现。

## 2. 已完成

### 产品与范围

- 已形成 P0 初版 PRD，明确最小闭环：

  ```text
  选择学习库 → 浏览项目和文章 → 阅读 Markdown → 提交反馈 → AI 生成并保存下一篇
  ```

- 已确认学习库是用户指定的本地文件夹，采用 `todo`、`ongoing`、`archive` 三类目录。
- 已确认 Markdown 文件是学习内容的主要真源。
- 已确认用户反馈追加到当前文章末尾，不单独建立反馈数据库。
- 已确认生成成功后停留在当前文章，只提示下一篇文章名称。
- 已确认 P0 不记录阅读时长、完成状态和学习统计，不集成 Neo Reader，不制作 Android APK。

### 技术方案

- 前端：React + Vite + TypeScript。
- 后端：Node.js + Express + TypeScript。
- 包管理器：npm。
- 数据保存：本地 Markdown 文件与简单 JSON 配置。
- 数据库：P0 不使用数据库。
- 已形成 P0 数据模型和 API 草案，共规划 6 个接口。
- 已确定第一条开发功能链先只实现“读取学习库并打开 Markdown 文章”，暂不接入反馈和 AI。

### 开发环境与代码

- 已确认本机安装 Node.js、npm、Git、GitHub CLI 和 VS Code。
- 已在 `client/` 初始化 React + Vite + TypeScript 项目。
- 已安装前端依赖并生成 `package-lock.json`。
- 已通过 `npm run dev` 启动开发服务器，并在 `http://localhost:5173` 看到 Vite 默认页面。

### 项目文档

- `docs/PRD.md`：P0 产品需求初稿。
- `docs/ARCHITECTURE.md`：技术栈、系统边界和核心数据流。
- `docs/DATA_MODEL_AND_API.md`：数据模型、API 草案和第一条功能链。
- `docs/STATUS.md`：记录当前进度、未完成事项和下一步。

## 5. 推荐的下一步

### 下一项任务：完成 UI Spec 初稿

先确定下面几个页面或状态：

1. 首次启动、尚未设置学习库。
2. 已设置学习库，打开上次阅读文章。
3. 浏览 `todo`、`ongoing`、`archive` 及其中的文章。
4. Markdown 阅读与文末反馈。
5. 提交后的生成中、生成成功和生成失败状态。
6. 电脑宽屏布局与 BOOX 窄屏布局。

UI Spec 确认后，开始第一条真实功能链：

```text
用户打开页面
  → 前端请求学习库列表
  → 后端扫描本地学习库
  → 前端显示项目和文章
  → 用户点击文章
  → 后端读取 Markdown
  → 前端渲染文章
```

建议实现顺序：

1. 用静态假数据把核心 UI 布局做出来。
2. 初始化最小 Express 后端。
3. 实现 `GET /api/library` 与 `GET /api/article`。
4. 用真实本地 Markdown 替换前端假数据。
5. 验证第一条读取功能链后，再开发反馈与 AI 生成。
