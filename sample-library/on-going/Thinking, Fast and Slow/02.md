# 02｜注意力与努力：为什么 System 2 总是很快就累了

## 这一篇要解决的问题

- System 2 的“努力”到底是什么？为什么费力任务会彼此干扰？
- 在学习、写代码或同时处理多个任务时，注意力如何被占满并出现“看不见”的失误？
- 练熟之后的“又快又准”到底发生了什么？它与 System 1/2 的边界怎样变化？
- 如何识别“高负荷＝高风险”的场景，并采取可执行的减载策略？

## 正文

一、先做一个 5 秒体验：加一

- 在心里打拍子（约 1 秒一次）。
- 想一个四位数字（比如 5294），两拍后把每一位都加一并读出（6305）。保持节奏。
- 如果这很轻松，试试“加三”。

你可能感到注意力被完全占满、节奏催促你“快点”、同时得记住刚听到的数、正在变换的数、和已经读出的数。研究显示，当你这样“冲刺式”用脑时，瞳孔会明显放大，心率上升；负荷在输出答案的那一刻达到峰值。可以把瞳孔想成“心理电表”：费力越大，“表”越走。

二、注意力是一笔预算，超支就会“看不见”

- 注意力是有限预算。两个费力任务几乎不能并行，否则其中一个会变差。
- 在冲刺时，大脑会优先保证最高优先级的任务，把其余输入“静音”。在类似“加一”任务的负荷峰值，人们会错过屏幕上清晰呈现的字母，即使眼睛正盯着那里。
- 这不是意志薄弱，而是资源调度：System 2 会精确地把资源留给主任务，其它刺激被忽略。

把它放进你的日常：

- 驾驶＋复杂心算这类“双费力”组合很危险；写代码时边回长消息边改核心逻辑，也是同类风险。
- 当你专注在调试或解题，容易错过“显眼但非主任务”的信息（例如日志里关键的一行、文档里的限制条件）。

三、三种常见的干扰源

- 并行的费力任务：例如同时做心算、比选多条件方案、在嘈杂环境里抓取特定声音。
- 任务切换：从“数 f 的次数”立刻改为“数逗号”，会明显变慢、更易出错。切换越频繁，成本越高。
- 时间压力＋多项并存：像杂耍一样要同时维持多球在空中，会被记忆衰退速度“逼着”加快，从而进一步推高负荷。

四、技能如何把任务“交给” System 1

- 随着练习，同一任务对能量的需求会下降，参与的脑区更少；同样的题，能力强的人投入的努力也更低。
- 这意味着：原本需要 System 2 才能做好的步骤，经过足够练习可以变成更自动的反应（更像 System 1 的执行）。
- 重要限定：本章的证据支持“更熟练＝更省力、更多自动化”，并不等于“更熟练＝在任何情境下都更可靠”。关于可靠性的边界，本章材料不足，下文不下定论。

五、把“高负荷＝高风险”做成可识别的信号
当出现以下任一信号时，把当前场景视为高风险，降低节奏或改变做法：

- 需要同时在脑中维持三四个以上的信息单元（中间结果、假设、变量状态）。
- 频繁在不同任务/窗口间来回切换。
- 明显的时间压力在驱动你加快。
- 出现“刚才那句没听见/那一行没看见”的瞬间空白。
- 你在做两个都费力的事情（例如一边比较多参数方案、一边组织精确表达）。

六、三步减载法（把 System 2 用在刀刃上）

- 设定任务集（只做一件）：用一句话明确此刻唯一目标，如“现在只验证输入是否为空”。这会覆盖默认反应，集中检索与此目标相关的信息。
- 外化中间结果：把待办、假设、变量值、关键条件写出来；把长任务拆成短步骤。这样不占用易溢出的工作记忆。
- 慢下来并分块：在切换前留一个“收尾句”（记录当前位置与下一小步），回来时就能快速续上，减少重新建模的代价。

七、应用到学习与写代码

- 学习
  - 读每一小段后写一句话总结；如果写不出，说明 System 2 还没把信息整合，继续输入只会堆负荷。
  - 在演算或推理中，随手把中间结论写下，避免用脑子“端着”。
- 写代码
  - 调试时把“现在验证什么”“预期状态是什么”写在注释/便签里；用断点/打印把关键状态外化，别全放在脑中记。
  - 处理核心逻辑时暂时静音通讯与提醒，减少任务切换；改完一个小步就提交或记录，形成稳定“锚点”。

八、两个微实验（随时可做）

- 切换成本：先在上一段文字里数“f”的出现次数，立刻改为数“，”的次数。留意速度与出错率的变化。
- 负荷与盲视：心里反复背一个六位数的同时，阅读一小段文字；结束后回忆要点与数字。你会体验到总有一项“掉球”。

## 小结

- System 2 的运作是费力的，注意力是一笔有限预算；两个费力任务会彼此干扰。
- 在负荷峰值，系统会优先保障主任务，导致对其它显眼信息的“选择性失明”。
- 任务切换与时间压力显著推高努力需求；最费力的慢思，常常被迫“快想”。
- 练熟会让原本费力的步骤变得自动化（更像 System 1 的执行），但“更省力”不必然等于“更可靠”（本章对此不下结论）。
- 把“高负荷”当成“高风险”来管理：设定任务集、外化中间结果、分块与放慢，是保护注意力的基础做法。
