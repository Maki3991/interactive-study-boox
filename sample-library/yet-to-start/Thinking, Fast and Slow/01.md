# 01｜两个系统：我们如何在意识到之前形成判断

## 这一篇要解决的问题

这本书为什么要把人的思维描述成两个“角色”？读完这一篇，你应该能区分自动、快速的 System 1 与需要注意力和努力的 System 2，并看到它们如何一起参与日常判断。

## 正文

### 先观察两个问题

先看一个熟悉的场景：你看到一个人的表情，很快判断出对方可能在生气，也会顺手猜测对方接下来要说什么。这个判断没有经过完整推理，印象先出现了。

再算一道题：

```text
17 × 24 = ?
```

你马上知道这是一道乘法题，也知道答案大概不会是 123 或 12,609。要得到准确答案，你需要调动学过的计算步骤，持续保持注意力，并暂时记住中间结果。这个过程更慢，也更费力。

书中把前一种活动称为 System 1，把后一种活动称为 System 2。

### System 1：先给出印象

System 1 运行得快，通常不需要主观意志的参与。它负责很多自动活动：

- 识别熟悉的物体和声音；
- 理解母语中的简单句子；
- 发现语气里的敌意；
- 完成“面包和……”这样的短语；
- 在熟悉领域快速发现模式。

这些能力有些来自先天，有些来自长期练习。熟练的阅读、驾驶和专业判断，都可能从需要努力的活动变成快速反应。

System 1 会持续向你提供印象、感觉、倾向和初步答案。很多时候，System 2 会直接接受这些建议，于是你感觉自己已经完成了判断。

### System 2：在困难处接管

System 2 负责需要注意力的活动，例如计算、比较、检查逻辑和抑制冲动。它可以把注意力集中在一个目标上，也可以暂时改变 System 1 的自动反应。

它的资源有限。你很难一边计算 `17 × 24`，一边在拥挤的车流中转弯。强行同时处理两个费力任务，通常会让其中一个任务变差。

当 System 1 没有立即给出答案、遇到意外，或者即将出现明显错误时，System 2 更容易被调动。例如，篮球传球实验中的大猩猩会让人意识到：注意力集中在一个任务上时，人可能看不见眼前很明显的东西。

### 两个系统是有用的称呼

System 1 和 System 2 不是大脑里各自住着一个小人，也不是两个可以被精确定位的脑区。它们是帮助我们描述两类思维活动的称呼。

把 System 1 想成“自动产生印象的角色”，把 System 2 想成“分配注意力、进行检查和控制行动的角色”，我们就能更容易讨论一个判断是怎样出现的。

这个称呼也提醒我们：很多进入意识的内容，已经经过了自动加工。我们通常先得到一个感觉，再决定是否检查它。检查动作需要 System 2 的注意力，因此不会在所有场景里自动发生。

### 这套分工为什么容易出错

两个系统的分工很节省心力。熟悉场景里，快速反应能让你顺利行动；遇到复杂任务时，慢速思考可以补充检查。

问题出现在：System 1 给出的答案听起来很完整，System 2 没有发现需要检查的信号。于是你可能对一个快速印象产生很高的信心，虽然它只利用了眼前的一小部分信息。

视觉错觉说明了这种限制。即使你已经用尺子确认两条线长度相同，眼睛仍可能把其中一条看成更长。知识改变了你的判断，知识没有立即改变自动产生的视觉印象。

认知判断也有类似情况。你可以学会识别某些容易出错的场景，在重要决定前主动放慢速度、寻找数据、比较其他解释。持续怀疑每个念头会消耗过多精力，所以更可行的做法是识别高风险场景，在关键处增加检查。

### 把它放回你的学习过程

阅读一段解释时，“我看懂了每句话”是一种快速印象。你能否用自己的例子重述、区分相近概念、预测一个新案例，才更接近可检验的理解。

接下来读书时，可以留意两个瞬间：

1. 哪个观点让你马上觉得“很有道理”？
2. 哪个地方迫使你停下来、计算、比较或重新组织信息？

这两个瞬间都值得记录。前者帮助你发现自动接受的印象，后者帮助你观察自己如何投入注意力。

## 小结

- System 1 快速、自动地生成印象和倾向。
- System 2 处理需要注意力、计算和控制的任务。
- System 2 经常接受 System 1 的建议，困难、意外和冲突会增加 System 2 的参与。
- 两个系统是描述思维活动的称呼，不是大脑中的两个独立器官。
- 重要决定需要识别高风险场景，并在这些场景里增加检查。
